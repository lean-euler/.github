## Prove it. Lean checks it.

We build an open-source platform of math problems where the answer is not a number but a **formal proof in Lean 4**. If the verifier accepts it, it is correct: no judges, no ambiguity.

-  A growing archive of problems, from induction to number theory
-  A sandboxed verifier with time and memory limits
-  Community-contributed problems, validated automatically by GitHub Actions
-  Made for students, teachers and anyone curious about formal mathematics

**Get involved:** pick up a `good first issue`, propose a problem, or help translate. Everyone is welcome, from first-time Lean users to experts.
